# 法序智演校赛版——法学定位与数据边界

## 产品定位
面向中国出海企业法务、商事争议代理律师的跨境争议事实梳理、仲裁准备、规则研究与模拟复盘工具。不是裁决预测系统，不替代执业律师，不协助真实仲裁员直接作出裁断。

## 角色
使用者身份与模拟角色分离：第一使用者企业法务，第二使用者代理律师，第三为教学研究人员。模拟角色为申请人代理、被申请人代理和仲裁员，不授予真实诉讼/仲裁权限。

## 仲裁术语
申请人 / 被申请人 / 仲裁庭 / 仲裁员 / 仲裁开庭 / 开庭审理 / 仲裁申请 / 答辩意见 / 仲裁裁决。内部旧标识 `Plaintiff`、`Defendant`、`Judge` 可保留兼容，对外不得展示法院/刑事诉讼误导性称呼。技术 Audit Trail 对外称来源追溯记录/过程留痕。

## 来源分类
1. 公开国际商事规则与官方规则解释：标注官方 URL、版本日期、适用前提。
2. 依法公开的司法裁判及可获授权的仲裁摘要：不得推定公开全文或当事人材料。
3. 当事人依法提供并授权的合同、邮件及证据：校赛公有部署不接受真实材料。
4. 标注 `synthetic_demo` 的合成案件和 `structured_demo` / `replay` 演示记录。

## 复核门槛
所有未核对原文、条号、版本及适用条件的规则设置 `reviewed:false`。未完成独立复核的研究包不能标为正式 Research Pack。未知事实必须保留 `unknown`，不得以模型常识补齐；CISG 第79条是否满足障碍、可预见性、可避免性、通知要求，必须逐项比对事实与证据。仅作争议准备研究，不对胜诉概率作定量宣称。

## 校赛演示真实性
实时模型输出必须标为 `live_llm` 且提示未经复核；结构化结果标为 `structured_demo`；预设听证为 `synthetic_replay`。画面 2D 不能宣传为原平台 Three.js 3D。匿名页面不得显示队伍或指导教师身份信息。
