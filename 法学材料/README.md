# 法学材料

不是运行入口。代码在 `mock_court_system/`。

```text
法学材料/
├── 指南与工作簿/   天天用：指南 + 简版工作簿
├── 案例材料/       只读：已下载的原文本体 + 已填标注（15 案，未复核）
└── 原始母表/       只读：A 组测试表、B 组目录、方法背景
```

- 指南和工作簿是填写规范，不是已标完的 10–20 案。
- 案例材料是原文本体与标注的存放处，明细与边界见 [`案例材料/README.md`](案例材料/README.md)。**标注尚未独立复核，不要当已复核数据用。**
- 原始母表是候选来源，不要改原值。
- 申报方案文在 `归档/申报材料/`，不在这里。
- 技术样例包在 `mock_court_system/data/research_packs/`，是夹具不是正式研究包；正式研究包计数仍为 0。
